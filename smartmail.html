Security & Privacy
API keys stay local

Keys saved in Settings stay in this browser. Groq can use the local backend so the Groq key does not appear in SmartMail or browser developer tools.

Emails are not stored by SmartMail

SmartMail loads messages into the browser while you use it. Guest messages and local labels are stored only in this browser.

AI uses your chosen provider

No AI runs until you choose a model or Auto-select. When you run an AI action, the needed email text is sent only to the provider you selected.

Cleanup is SmartMail-only

The AI cleanup tool hides selected emails inside SmartMail. It does not delete messages from Gmail.
