# SmartMail

SmartMail is an AI-powered email assistant designed to make inbox management faster, cleaner, and less stressful.

## Features

- Modern email dashboard
- Smart reply interface
- AI workflow concepts
- Gmail-focused design
- Follow-up management
- Inbox cleanup tools
- Dark mode support
- Responsive UI

## Browser regression tests

From this folder, run `python3 -m http.server 8000 --bind 127.0.0.1`, then open `http://127.0.0.1:8000/tests/sanitize-email.html`. The page checks the email sanitizer directly without starting Gmail or AI integrations. All 16 checks should pass.

## Vision

SmartMail aims to become an intelligent email companion that can:

- Summarize emails
- Generate smart replies
- Organize inboxes
- Detect important messages
- Reduce email overload
