FAQ

Questions before launch.

Clear answers for users who care about privacy, Gmail access, and AI behavior.

Does SmartMail store my emails?

SmartMail loads email content into the browser while you use it. Guest messages and local labels are stored in the current browser. Gmail remains the source of truth.

Does AI run automatically?

No. SmartMail starts with AI off. AI actions run only after you choose a model or enable Auto-select.

How does Groq stay hidden from the browser?

The Groq backend keeps the API key in a local backend file or environment variable. The browser calls the backend URL instead of seeing the key directly.

Can cleanup delete Gmail messages?

The AI cleanup flow is SmartMail-only by design. It hides selected messages inside SmartMail so users can stay safe while reviewing suggestions.

Is this production hosted?

This landing page is built as a production-ready SaaS front door. The current SmartMail app runs locally and can be extended into a hosted product.
